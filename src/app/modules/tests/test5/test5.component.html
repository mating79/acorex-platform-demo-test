Workflow designer (demo)

Drag activities onto the canvas. Move nodes from the body; resize when a node is active. Connect blue (outbound) to green (inbound). This demo models a production-grade Register User + OTP orchestration with UI, backend, security, and integration actions (rate-limit, fraud check, event publishing). Multi-select works with Ctrl/Cmd + click; drag one selected node to move all selected nodes.
